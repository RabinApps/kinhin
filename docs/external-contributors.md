# Adding your company or project to the list

If your company or project uses **kinhin**, you can add it to the list so the
community can see who else is running it.

## How to add yourself

1. Open a pull request against `main` with a single entry in the list below.
2. The entry format is:

   ```markdown
   - [Your Project](https://your-project-url) — one-line blurb of what you use
     kinhin for.
   ```

3. Keep the name lowercase, use your project's own domain for the link, and keep
   the blurb to one line.

## Review

A maintainer reviews the PR for link and wording. Once merged, the contribution
appears on the website and in the app's **Advanced → App** section (and in
`kinhin support` output after a rebuild).

## Code of conduct

Treat sponsors and users alike. Listing is a way of saying "this project runs on
kinhin" and carries the same expectations as the project's own code of conduct.
