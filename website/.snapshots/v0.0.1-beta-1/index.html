// WHAT YOU GET

What you get

In beta

GitHub, Gitea, Forgejo and GitLab CE are supported. Gitea, Forgejo and GitLab CE run end to end on every runtime in kinhin's own test suite; GitHub has run on Tart macOS VMs and apple/container. Buildkite, Azure Pipelines and Bitbucket are planned. <a href="/guide/forges#what-has-been-tested">What has been tested</a> · <a href="/guide/beta-roadmap">Roadmap to v0.1.0</a>

Real concurrency

Self-hosted runners handle one job at a time. Kinhin scales a fleet of ephemeral runners to your queue so jobs run in parallel. <a href="/guide/why-kinhin">Why kinhin</a>

Ephemeral by default

Every job gets a fresh VM or container. The runner deregisters itself afterwards and the instance is deleted — no state leaks between jobs.

Multi-forge

GitHub Actions, GitLab CI/CD, Gitea Actions and Forgejo Actions served from one shared pool. Buildkite, Azure Pipelines and Bitbucket Pipelines are planned.

Multi-runtime

macOS jobs on Tart VMs, Linux jobs on apple/container microVMs, Docker containers, or Tart Linux VMs — each job routed by repo, workflow, or runs-on label.

Resource-aware

The scaler never exceeds what your Mac can handle. Host CPU, memory, and disk headroom are always reserved, and the budget is partitioned across runtime pools.

Menu bar or headless

The same engine behind a macOS menu bar app or a LaunchAgent daemon — same config, either way, exactly one fleet.

One-line install

curl … \| bash from GitHub Releases with sha256 verification, no Gatekeeper dance, and a clean uninstall.
