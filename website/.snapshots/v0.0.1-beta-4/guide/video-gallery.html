GUIDE / PRODUCT VIDEOS

Video gallery

View .mdEdit on GitHub

Every video below is built from a JSON file in video/script/ with one command, in a container, from committed sources. Each picture is a frame from each scene of the real build. To make one of your own, copy a file into your repository's .kinhin/videos/ and run kinhin video build <name> (see Add videos to your project). video/scripts/gallery.mjs rebuilds all of this page and writes a page where you can play the videos.
