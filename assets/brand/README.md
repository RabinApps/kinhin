# Brand assets

kinhin's logo is a black ring (an unfilled circle) on white.

- `icon.svg` — app icon: 824 px white squircle on a 1024 canvas (100 px margin), 512 px outer-diameter black ring with a 32 px stroke, 1 px hairline.
- `mark.svg` — the ring alone, `currentColor`, for the website nav bar.
- `AppIcon.iconset/`, `AppIcon.icns` and the `website/public/` favicons, touch icon and OG image are **generated**;
  don't hand-edit them. Regenerate with `swift scripts/make-icons.swift` and commit the result.
